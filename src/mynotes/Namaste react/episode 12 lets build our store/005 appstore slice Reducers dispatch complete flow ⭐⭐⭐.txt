# 🏗️ Understanding the Libraries

Before writing code, understand the responsibility of each library.

---

## ⚛️ React

React is responsible for:

✅ Creating Components

✅ Rendering UI

✅ Handling Events

Examples:

```javascript
useState()
useEffect()
useContext()
```

React knows nothing about Redux.

---

## 🏪 Redux Toolkit

Imported from:

```javascript
import {
  configureStore,
  createSlice
} from "@reduxjs/toolkit";
```

Redux Toolkit is responsible for:

✅ Creating Store

✅ Creating Slices

✅ Creating Reducers

✅ Creating Actions

✅ Managing Application State

Think:

```text
Redux Toolkit
      ↓
Creates Store
Creates Slice
Creates Reducers
Creates Actions
```

---

## 🌉 React Redux

Imported from:

```javascript
import {
  Provider
} from "react-redux";
```

React Redux acts as a bridge between:

```text
React  ←→  Redux
```

Without React Redux:

❌ React cannot access Redux Store

With React Redux:

✅ React components can access Redux Store

# ⭐ Step 1 : Creating Slice

File:

```javascript
cartSlice.js
```

Code:

```javascript
const cartSlice = createSlice({
    name: "cart",
    initialState: {
        items: []
    },
    reducers: {
        addItem(){},
        removeItem(){},
        clearCart(){}
    }
});
```

---

## 📌 What is a Slice?

A Slice is a feature-wise container.

Example:

```text
cartSlice
```

stores:

```javascript
{
   items: []
}
```

Other possible slices:

```text
userSlice
productSlice
orderSlice
wishlistSlice
```

---

# ⭐ Step 2 : Creating Reducers

Inside Slice:

```javascript
reducers : {
   addItem(){},
   removeItem(){},
   clearCart(){}
}
```

---

## 📌 What is a Reducer?

A Reducer is a function that updates the state.

Example:

```javascript
addItem : (state,action) => {
   state.items.push(action.payload);
}
```

Meaning:

```text
If ADD_ITEM action comes,
add product into cart.
```

---

### Reducers We Created

#### ⭐ addItem

```javascript
addItem : (state,action) => {
   state.items.push(action.payload);
}
```

Purpose:

```text
Add new item into cart
```

---

#### ⭐ removeItem

```javascript
removeItem : (state,action) => {
   state.items.pop();
}
```

Purpose:

```text
Remove item from cart
```

---

#### ⭐ clearCart

```javascript
clearCart : (state,action) => {
   state.items = [];
}
```

Purpose:

```text
Remove all items from cart
```

---

# ⭐ Step 3 : Actions Are Automatically Created

This is one of the biggest benefits of Redux Toolkit.

We wrote:

```javascript
reducers : {
   addItem(){},
   removeItem(){},
   clearCart(){}
}
```

Redux Toolkit automatically creates:

```javascript
addItem
removeItem
clearCart
```

actions for us.

---

We export them:

```javascript
export const {
  addItem,
  removeItem,
  clearCart
} = cartSlice.actions;
```

---

### 📌 Important Point

We never manually created:

```javascript
{
   type: "ADD_ITEM"
}
```

Redux Toolkit automatically generates these action creators.

---

# ⭐ Step 4 : Exporting Reducer

We export:

```javascript
export default cartSlice.reducer;
```

---

### 📌 Why?

Because Store needs Reducers.

Store does not need Actions.

Store only needs Reducers.

---

# ⭐ Step 5 : Creating Store

File:

```javascript
appStore.js
```

Code:

```javascript
const appStore = configureStore({
   reducer : {
      cart : cartReducer,
      user : userReducer
   }
});
```

---

## 📌 Important Understanding

Many beginners get confused here.

Inside Slice:

```javascript
reducers : {
   addItem(){},
   removeItem(){},
   clearCart(){}
}
```

Inside Store:

```javascript
reducer : {
   cart : cartReducer
}
```

These are NOT the same thing.

---

### Inside Slice

```javascript
reducers
```

means:

```text
Functions that update state
```

Example:

```text
addItem()
removeItem()
clearCart()
```

---

### Inside Store

```javascript
reducer
```

means:

```text
Which slice should manage this part of store?
```

Example:

```javascript
reducer : {
   cart : cartReducer
}
```

Meaning:

```text
cart data
      ↓
managed by cartReducer
```

---

# ⭐ Final Store Structure

After Store Creation:

```javascript
{
   cart : {
      items : []
   },

   user : {
      ...
   }
}
```

Store contains multiple slices.

Imported from:

## 📌 Why Provider?

Provider shares the Store with the entire application.

Without Provider:

```text
React Components
      ❌
Cannot Access Store
```

With Provider:

```text
React Components
      ✅
Can Access Store
```

---

Code:

```jsx

   <App />
</Provider>
```

---

### Meaning

```text
Make appStore available
to every component
inside App
```

# ⭐ Complete Architecture

```text
createSlice()
      ↓
Creates
Reducers + Actions
      ↓
Reducer Exported
      ↓
configureStore()
      ↓
Store Created
      ↓
Provider
      ↓
Store Shared To React
      ↓
Application Ready
```

---

# 🎤 Interview Explanation

### What have you done till now in Redux Toolkit?

> We created a cartSlice using createSlice(). Inside the slice, we defined reducers such as addItem, removeItem, and clearCart. Redux Toolkit automatically generated action creators for these reducers. We exported the reducer and registered it inside configureStore() while creating the Redux Store. Finally, we wrapped our application with Provider from react-redux so that the Redux Store becomes available to all React components.

---

# 🧠 Easy Memory Trick

```text
Redux Toolkit
    ↓
createSlice()
    ↓
Reducers + Actions
    ↓
configureStore()
    ↓
Redux Store
    ↓
Provider
    ↓
Entire React App
```

⭐ Redux Toolkit = State Management Logic

⭐ React Redux = Bridge Between React and Redux

⭐ Provider = Makes Store Available To Entire Application

## What Happens?

User clicks:

```text
Add To Cart
```

↓

```javascript
dispatch(addItem(product))
```

↓

Redux creates Action:

```javascript
{
   type: "cart/addItem",
   payload: product
}
```

↓

Reducer executes:

```javascript
addItem(state, action)
```

↓

Store updates.


---

## 📌 What is useSelector?

useSelector is used to read data from Redux Store.

Example:

```javascript
const cartItems =
useSelector(
   (store) => store.cart.items
);
```

Meaning:

```text
Read Cart Data
From Redux Store
```

---

# ⭐ Step 11 : Store Subscription

When useSelector is used:

```javascript
const cartItems =
useSelector(
   (store) => store.cart.items
);
```

Component automatically subscribes to Redux Store.

```text
Store Changes
      ↓
Selector Detects Change
      ↓
Component Re-renders
```

# 🎤 Interview Summary

### What have you learned in Redux Toolkit?

> We created a cartSlice using createSlice() and defined reducers such as addItem, removeItem, and clearCart. Redux Toolkit automatically generated actions for these reducers. We configured the Redux Store using configureStore() and connected it to React using Provider. We used useDispatch() to send actions to Redux and useSelector() to read data from the store. When actions are dispatched, reducers update the store, and subscribed components automatically re-render with the latest data.
