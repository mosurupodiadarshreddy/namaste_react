# ⭐ Redux Toolkit (RTK) Basics – Slice, Action, Dispatch & Reducer ⭐

## 🚀 Introduction

When learning Redux Toolkit, the most important concepts to understand are:

⭐ **Slice**

⭐ **Action**

⭐ **Dispatch**

⭐ **Reducer**

These concepts work together to update application data in a predictable way.

---

# ⭐ What is a Slice?

### 📌 Definition

A **Slice** is a logical section of application state that manages data related to a specific feature.

👉 Simple Meaning:

> **One Feature = One Slice**

Examples:

```text
cartSlice      → Cart Data
userSlice      → User Information
productSlice   → Product Data
orderSlice     → Order Data
```

---

## 🛒 Cart Slice Example

Suppose we are building an E-Commerce application.

We need to store:

```text
Products added to cart
```

We create:

```text
cartSlice
```

This slice is responsible only for cart-related data.

Example:

```javascript
cartSlice

{
   items: []
}
```

Whenever products are added or removed, the cartSlice will be updated.

---

# ⭐ What is an Action?

### 📌 Definition

An **Action** is an object that describes what happened in the application.

👉 Simple Meaning:

> An Action is simply a message sent to Redux.

Example:

```text
"Add this product to cart"
```

or

```text
"Remove this product from cart"
```

Examples:

```javascript
{
   type: "ADD_ITEM"
}
```

```javascript
{
   type: "REMOVE_ITEM"
}
```

---

# ⭐ What is Dispatch?

### 📌 Definition

**Dispatch** is a method used to send an Action to Redux.

👉 Simple Meaning:

> Dispatch means informing Redux that something happened.

Example:

```javascript
dispatch(addItem(product));
```

Here we are telling Redux:

```text
"Please add this product into cart"
```

---

# ⭐ What is a Reducer?

### 📌 Definition

A **Reducer** is a function that decides how the state should change when an action is received.

👉 Simple Meaning:

> Reducer contains the logic to update the data.

Example:

```text
Action Received:
ADD_ITEM

Reducer Logic:
Add Product Into Cart
```

The reducer updates the cart data internally.

---

# ⭐ Complete Add To Cart Flow

Suppose the user clicks:

```jsx
<button>Add To Cart</button>
```

The following steps happen:

---

## Step 1️⃣ User Clicks Button

```text
User Clicks Add To Cart
```

---

## Step 2️⃣ Dispatch Sends Action

```javascript
dispatch(addItem(product));
```

Redux receives the action.

```text
ADD_ITEM Action Sent
```

---

## Step 3️⃣ Reducer Function Executes

Redux finds the corresponding reducer.

```javascript
addItem(state, action)
```

The reducer contains the logic:

```text
Add Product To Cart
```

---

## Step 4️⃣ Cart Gets Updated

Before:

```javascript
{
   items: []
}
```

After:

```javascript
{
   items: [
      Laptop
   ]
}
```

The cart state is now updated.

---

## Step 5️⃣ UI Updates Automatically

The cart count changes.

Example:

Before:

```text
Cart (0)
```

After:

```text
Cart (1)
```

The user immediately sees the updated cart.

# ⭐ Interview Explanation

### What is a Slice?

> A Slice is a logical section of application state responsible for managing a specific feature such as cart, user, product, or orders. Redux Toolkit uses slices to organize application state in a feature-based manner.

---

### What is an Action?

> An Action is a JavaScript object that describes what happened in the application. Examples include adding an item to the cart or removing an item from the cart.

---

### What is Dispatch?

> Dispatch is used to send an action to Redux. It notifies Redux that an event has occurred and that the state may need to be updated.

---

### What is a Reducer?

> A Reducer is a function that receives an action and updates the state based on that action. It contains the business logic for modifying application data.

---

### Explain Add To Cart Flow

> When a user clicks the Add To Cart button, an action is dispatched. Redux receives that action and executes the corresponding reducer function. The reducer updates the cart state, and React automatically re-renders the UI to display the updated cart information.
