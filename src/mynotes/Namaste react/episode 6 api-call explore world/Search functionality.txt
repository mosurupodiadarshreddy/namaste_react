now we  will add this html functionality right : (when ever state variable updates react re-renders whole component )

Step 1️⃣ Adding Search HTML UI

First we add the UI.

<div className="search-bar">
  <input type="text" placeholder="search 🔍" className="searchbox" />
  <button className="search-button">Search</button>
</div>

This is only HTML UI.

Currently:

Input accepts text

Button does nothing

So next we add React state + logic.

Step 2️⃣ Making Input a Controlled Component

You added state:

const [searchText, setSearchText] = useState("");

Now connect input with state.

<input
  type="text"
  placeholder="search 🔍"
  className="searchbox"
  value={searchText}
  onChange={(e) => {
    setSearchText(e.target.value);
  }}
/>

Now this is called a Controlled Component.

What happens while typing?

Example: User types "p"

e.target.value = "p"

React runs:

setSearchText("p")

State becomes:

searchText = "p"

Component re-renders.

Input value becomes:

value = "p"

So text appears in input.

Step 3️⃣ Why value without onChange does not allow typing

Example:

<input value={searchText} />

If searchText = ""

React always forces input value to:

""

User types "p".

But React again renders:

value=""

So typing disappears immediately.

Because:

value is controlled by React

But React state is not updating.

That is why onChange is mandatory.

Correct pattern:

value={searchText}
onChange={(e)=> setSearchText(e.target.value)}
Step 4️⃣ React Diffing While Typing

Example user types:

pizza

Typing flow:

p → pi → piz → pizz → pizza

Every key press:

setSearchText()

React does:

State change
↓
Component re-render
↓
New Virtual DOM
↓
Diff with previous Virtual DOM
↓
Update only input value

React does not re-render whole page.

Only this changes:

<input value="p">
<input value="pi">
<input value="piz">

React updates only input element.

Step 5️⃣ Search Logic

When clicking search:

const searchedList = ListofRestros.filter(
  (res) => res.info.name.toLowerCase().includes(searchText.toLowerCase())
);

Let's understand this.

Step 6️⃣ What filter() does

filter() returns items that match condition.

Example:

Restaurants

Dominos Pizza
Pizza Hut
Burger King
KFC

Search:

pizza

Filter result:

Dominos Pizza
Pizza Hut
Step 7️⃣ === vs includes()
❌ Strict match
res.info.name === searchText

Example:

Restaurant = "Dominos Pizza"
Search = "pizza"

Result:

false

Because:

"Dominos Pizza" !== "pizza"

Strict match must be exact.

✅ includes()
res.info.name.includes(searchText)

Example:

"Dominos Pizza".includes("pizza")

But this returns false because of case difference.

Step 8️⃣ Case Insensitive Search

To solve that:

res.info.name.toLowerCase().includes(searchText.toLowerCase())

Example:

Restaurant = "Dominos Pizza"
Search = "pizza"

Convert both:

"dominos pizza".includes("pizza")

Result:

true

Now it matches.

Step 9️⃣ Problem with First Code

Your old code:

const searchedList = ListofRestros.filter(...)
setListofRestros(searchedList);

Example flow:

Initial list

100 restaurants

Search:

pizza

Now list becomes:

10 restaurants

Next search:

burger

Now filter happens on 10 restaurants only.

But burger restaurant might be in original 100 list.

So search results become wrong.

Step 🔟 Correct Solution

Keep two states.

Original List
Filtered List

You did this:

const [ListofRestros,setListofRestros] = useState([]);
const [filteredRestros,setFilteredRestros] = useState([]);

Meaning:

ListofRestros → Original data
filteredRestros → What we display
Step 1️⃣1️⃣ When API Loads
setListofRestros(restrodata);
setFilteredRestros(restrodata);

Now both contain:

100 restaurants
Step 1️⃣2️⃣ When Searching

Now you filter original list.

const searchedList = ListofRestros.filter(...)
setFilteredRestros(searchedList);

So:

Original list → unchanged
Filtered list → updated
Step 1️⃣3️⃣ Rendering

Now UI uses:

filteredRestros.map(...)

So only filtered restaurants show.

Step 1️⃣4️⃣ Complete Search Flow
API fetch
↓
ListofRestros = full data
filteredRestros = full data
↓
User types "pizza"
↓
searchText updates
↓
User clicks Search
↓
filter(ListofRestros)
↓
filteredRestros updated
↓
React re-render
↓
UI shows filtered restaurants
🚀 Final Architecture
ListofRestros (original)
        ↓
filter()
        ↓
filteredRestros
        ↓
UI render
