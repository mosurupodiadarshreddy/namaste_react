A Higher Order Component (HOC) in React is a function that takes a component as input and returns a new enhanced component with additional features or behavior.

Simple definition:

“A Higher Order Component is a function that wraps another component to add extra functionality.”

Syntax:

const EnhancedComponent = HigherOrderComponent(OriginalComponent);

Example:

const withLabel = (Component) => {
  return (props) => {
    return (
      <div>
        <h1>Special Offer</h1>
        <Component {...props} />
      </div>
    );
  };
};

Using it:

const EnhancedRestaurantCard = withLabel(RestaurantCard);

Now EnhancedRestaurantCard will show:

“Special Offer”
plus original RestaurantCard

Real project uses of HOC:

Authentication checking
Role-based access
Loading spinner handling
Logging
Reusable permissions
API/error handling

Interview one-line answer:

“HOC is an advanced React pattern used for reusing component logic by wrapping a component inside another component.”

What is HOC Syntax?

Basic syntax:

const HigherOrderComponent = (Component) => {
  return (props) => {
    return <Component {...props} />;
  };
};

Breakdown:

| Part                       | Meaning                                     |
| -------------------------- | ------------------------------------------- |
| `Component`                | Original component coming as input          |
| `(props)`                  | Props received by new enhanced component    |
| `<Component {...props} />` | Rendering original component with all props |
