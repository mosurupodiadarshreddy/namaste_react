1. What is Dynamic Routing?

Dynamic routing means:
The URL contains a variable value (like id), and based on that value we load different data.

Example URLs:
/restaurant/101
/restaurant/102
/restaurant/205

Here 101, 102, 205 are dynamic values → restaurant IDs.

2. Route Configuration
You wrote:
{
  path: "/restaurant/:resId",
  element: <Restaurant/>
}
What is :resId?
The : means dynamic parameter.

So React Router understands:
Whatever comes after /restaurant/ will be stored in a variable called resId.

1. Imports
import { useEffect, useState } from "react";
import Shimmer from "./Shimmer";
import { Link } from "react-router-dom";
What these are:
| Import    | Purpose                       |
| --------- | ----------------------------- |
| useState  | Store API data                |
| useEffect | Call API when component loads |
| Shimmer   | Loading UI                    |
| Link      | Navigate back to home         |

2. State Variable
const [menuData, setMenuData] = useState(null);
Meaning:
menuData → stores product/menu data from API
setMenuData → updates state
Initial value = null because data not loaded yet

Flow:

Initial render → menuData = null
After API → menuData = product object
Component re-renders
3. useEffect
useEffect(() => {
  fetchMenu();
}, []);
Important concept:

This means:

Call fetchMenu() only once when component loads.

Because dependency array is empty [].

Flow:

Component loads
   ↓
useEffect runs
   ↓
fetchMenu()
   ↓
API call
   ↓
setMenuData()
   ↓
Component re-renders
4. Fetch Function
const fetchMenu = async () => {
  const data = await fetch("https://dummyjson.com/products/" + 1);
  const json = await data.json();
  console.log(json);
  setMenuData(json);
};
Step by step:
fetch() → get response
await data.json() → convert response to JSON
setMenuData(json) → store in state
React re-renders component

So now:

menuData = {
  id: 1,
  title: "...",
  price: ...,
  rating: ...
}
5. Conditional Rendering (Very Important)
if (!menuData) return <Shimmer />;

This means:

If menuData is null → show loading shimmer
Else → show menu page

Render flow:

First render → menuData null → Shimmer
After API → menuData has data → Show menu

This is called:

Conditional Rendering
